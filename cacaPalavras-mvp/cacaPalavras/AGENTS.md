# Instruções para agentes

Os PRDs devem ser _sempre_ criados na raiz do projeto atual, seguindo o formato `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.

## Princípios de trabalho
- Leia `PRD.md`, `SPECS.md` e o plano em `docs/plans/` antes de alterar o produto.
- Preserve HTML semântico, navegação por teclado, contraste adequado e mensagens de estado acessíveis.
- Não adicione dependências sem necessidade; o MVP usa HTML, CSS e JavaScript nativos.
- Atualize testes e documentação quando alterar comportamento.
- Não declare testes, auditorias, agentes ou publicação remota que não tenham sido realmente executados.
