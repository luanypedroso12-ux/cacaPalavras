# cacaPalavras

MVP web de jogo diário híbrido: adivinhar palavra e caça-palavras. Feito com HTML, CSS e JavaScript nativos.

## Executar localmente

O service worker e a experiência PWA precisam de `localhost` ou HTTPS. Com Python instalado, na pasta do projeto execute:

```bash
python3 -m http.server 8000
```

Abra `http://localhost:8000`.

## Conteúdo
- `PRD.md`: requisitos e critérios de aceite.
- `SPECS.md`: arquitetura e especificação técnica.
- `AGENTS.md`: instruções para agentes.
- `docs/plans/`: plano datado.
- `prototypes/`: três direções visuais navegáveis.
- `tests/TEST-PLAN.md`: checklist de validação manual.

## Observações
O catálogo de palavras é pequeno e demonstrativo. O projeto ainda precisa de revisão editorial, testes reais de acessibilidade e regressão em navegadores antes de ser considerado pronto para produção. Não há repositório remoto GitHub criado por este pacote.
